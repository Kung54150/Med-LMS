แก้ตำแหน่ง/ระดับแล้วระบบบันทึกทันทีเมื่อเปลี่ยนค่าในช่อง
เลือกพนักงานและเดือน แล้วกด "Refresh" — คลิกปุ่มจัดการในตารางเพื่อ "เลือกไว้" ก่อน (ปุ่มจะเปลี่ยนเป็นสีส้ม) เลือกได้หลายวันพร้อมกัน แล้วค่อยกด "บันทึกการเปลี่ยนแปลงทั้งหมด" ครั้งเดียวตอนเลือกครบ ระบบนี้ไม่ติดล็อกเดดไลน์ แก้ไขได้แม้เลยกำหนดของพนักงานแล้ว — ถ้าวันไหนโควต้าประเภทนั้นเต็มแล้ว (ตัวเลขจะขึ้นสีแดง) ปุ่มของประเภทนั้นจะกดไม่ได้ ต้องไปยกเลิกคำขอของคนอื่นในวันนั้นให้ไม่เต็มก่อนถึงจะเลือกให้พนักงานคนนี้ได้
แต่ละแถว = เวลาเข้า-ออกของพนักงาน 1 คนในวันนั้น เช่น "คนที่ 1: 7.00–17.00" — ถ้ามีคนอื่นทำเวลาเดียวกันอีก ให้กดปุ่ม "+ เพิ่มคน" แล้วกรอกช่วงเวลาเดิมซ้ำได้เลย (นับเป็นคนละแถว/คนละคน) แก้ไขได้ทุกเดือน เพราะจำนวนคนแต่ละเดือนไม่เท่ากัน ใช้รูปแบบเวลาแบบ "7.00" หรือ "7:00" ก็ได้
เฉพาะกลุ่ม RN — ท้ายแต่ละวันมีช่อง "ต้องมีคนขึ้น CP อย่างน้อย ___ คน" ถ้ากรอกไว้มากกว่า 0 ตัวสร้างตารางร่างจะจัดคนไป CP ให้ครบตามจำนวนนี้อัตโนมัติ (เอาคนที่ขอ CP เองมาก่อน แล้วเลือกคนที่ขึ้นเวรสะสมน้อยที่สุดมาเติมให้ครบ พร้อมแจ้งเตือนให้ตรวจสอบ) ถ้าเว้นว่างหรือใส่ 0 ไว้ ระบบจะยึดตามคำขอ CP ของพนักงานเองเหมือนเดิม (แค่เตือนถ้าวันนั้นไม่มีใครขอ CP เลย) — ควรตั้งเลขนี้ให้สอดคล้องกับ "CPSlots" (เพดานจำนวนคนขอ CP ได้) ในแท็บโควต้าต่อวันด้วย ไม่ให้ขัดกันเอง

วันหยุดนักขัตฤกษ์ของเดือนนี้

วันที่ตั้งไว้ตรงนี้ ตัวสร้างตารางร่างจะใช้ Pattern แบบวันอาทิตย์ในการคำนวณของวันนั้น (ปรับจำนวนคนเองได้ในตารางร่างถ้าไม่ตรงกับความเป็นจริง)

ชั่วโมงบังคับของเดือนนี้

เก็บไว้ใช้คำนวณชั่วโมงรวม/OT ในเฟสถัดไป ตอนนี้ตัวสร้างตารางร่างยังไม่ได้ใช้ตัวเลขนี้คำนวณอัตโนมัติ
สร้างจากคำขอที่อนุมัติแล้ว + Pattern อัตรากำลังของเดือนนี้ — เป็นแค่ "ร่าง" อัตโนมัติ ยังไม่ครอบคลุมทุกกติกา (เช่น การเกลี่ยชั่วโมงรวมแบบละเอียด) กรุณาตรวจสอบทุกจุดที่ระบบแจ้งเตือน และสลับคนในช่อง dropdown ได้ตามต้องการ ก่อนกด "บันทึกตารางเวรนี้"
ปุ่ม "เปิดตาราง Excel (พนักงาน x วันที่)" จะสร้างชีตใหม่ในสเปรดชีตนี้ รูปแบบแถว=รายชื่อพนักงาน (2 แถวย่อยต่อคน บน=เวลาเข้า ล่าง=เวลาออก) คอลัมน์=วันที่ 1 ถึงสิ้นเดือน เหมือนฟอร์แมตตารางเวรเดิมของ รพ. — เปิดแล้วไปที่เมนู File > Download > Microsoft Excel (.xlsx) เพื่อได้ไฟล์ Excel ได้เลย (สร้างจากข้อมูลล่าสุดที่เห็นบนจอ ไม่ต้องกดบันทึกตารางเวรก่อนก็ได้)
